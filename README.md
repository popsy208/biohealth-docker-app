# 🚀 Automated HTML Web App Deployment with Docker & CI/CD

> A modern DevOps project demonstrating containerization, automation, and continuous deployment using Docker, GitHub Actions, and HTML/CSS.

---

## 📌 Project Overview

This project demonstrates how a simple static HTML application can be transformed into a production-ready DevOps pipeline using modern tools and practices.

It is containerized with Docker and automatically built, tested, and deployed using a CI/CD pipeline powered by GitHub Actions.

This project reflects real-world DevOps engineering skills including automation, containerization, and cloud-ready deployment workflows.

---

## 🛠️ Tech Stack

- HTML5 – Frontend structure  
- CSS3 – Styling and responsiveness  
- Docker – Application containerization  
- GitHub Actions – CI/CD automation  
- NGINX – Web server  
- Linux – Deployment environment  
- GitHub – Version control  

---

## 📂 Project Structure

- index.html → Main webpage  
- style.css → Styling file  
- Dockerfile → Container configuration  
- nginx.conf → Web server configuration  
- .github/workflows/ → CI/CD pipeline setup

## 🔄 CI/CD Pipeline

### Pipeline Flow

Developer pushes code → GitHub Actions triggers → Docker image builds → Container tested → Deployment executed → Application goes live

---

### GitHub Actions Workflow

- Triggered on push to main branch  
- Checks out repository code  
- Builds Docker image  
- Runs container test to validate deployment
